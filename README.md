# เบาเบา (Baobao Money)

เว็บช่วยจัดระเบียบรายรับ–รายจ่ายแบบภาษาไทย โดยเก็บข้อมูลไว้ในเบราว์เซอร์ของผู้ใช้

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือใช้ static server เช่น:

```sh
ruby -run -e httpd . -p 4173
```

จากนั้นเปิด `http://localhost:4173`

## ความสามารถ

- เพิ่มและแก้ไขรายรับ–รายจ่าย
- เลือกเดือน ดูยอดสรุปและสัดส่วนหมวดรายจ่าย
- ค้นหาและกรองรายการ
- เพิ่มบิลและรายได้ประจำ
- ตั้งเป้าหมายการเงิน
- นำเข้าไฟล์ CSV รูปแบบ `date,name,amount,category,type`
- สำรองข้อมูลเป็น JSON หรือเริ่มต้นข้อมูลใหม่

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ไม่มีการส่งข้อมูลการเงินไปยังเซิร์ฟเวอร์
